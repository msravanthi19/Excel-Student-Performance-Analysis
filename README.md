# Student Performance Analysis Using Microsoft Excel

## Project Overview
This project focuses on analyzing student academic performance using Microsoft Excel.

It is a practical Excel learning project created as part of my Data Analytics learning journey.

## Objective
To calculate student performance, analyze subject-wise marks, identify Pass/Fail results, and visualize the insights using charts.

## Tools Used
- Microsoft Excel

## Dataset
- Sample student records
- Five subjects: English, Maths, Science, Computer, and Social
- Student names, IDs, cities, and marks

## Excel Concepts Practiced
- SUM
- AVERAGE
- MAX and MIN
- MEDIAN
- COUNT and COUNTA
- IF, AND, OR
- COUNTIF
- Data Analysis
- Column Charts
- Pie Charts
- Dashboard Creation

## Project Work
1. Created a student marks dataset.
2. Calculated total and average marks.
3. Identified highest and lowest subject marks.
4. Applied IF and AND functions to calculate Pass/Fail results.
5. Used COUNTIF to calculate Pass and Fail student counts.
6. Calculated subject-wise average marks.
7. Created a Dashboard with charts to visualize student performance.

## Key Learning
Learned how to use Excel formulas, analyze student data, and present insights through visualizations.

## Project Type
Beginner-level Excel Data Analysis Project.

Created as part of my Excel and Data Analytics learning journey.
